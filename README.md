# THITRONIK Pro-finder – Barrierefreiheits-Pilot

Pilot für eine durchgängig barrierefreie Produktkommunikation des THITRONIK Pro-finder:
barrierefreie Setup-Karte, HTML-first-Anleitung mit Versionsauswahl (bis SN-044 / ab SN-045),
seitenweise PDF-Prüfung, versioniertes Content-, Glossar- und Übersetzungssystem.

Dieser Commit ist ein Bootstrap-Platzhalter auf `main`. Alle Inhalte kommen über
Pull Requests, beginnend mit `bootstrap/accessibility-pilot`.
